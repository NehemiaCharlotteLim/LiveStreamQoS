CARA MENGGANTI FOLDER DI GITHUB (STREAMLIT CLOUD)

1. Ekstrak ZIP ini. Di dalamnya ada folder LiveStreamQoS_Cloud berisi 5 file.
2. Di GitHub, masuk ke repository NehemiaCharlotteLim/LiveStreamQoS, branch main,
   kemudian masuk ke folder LiveStreamQoS_Cloud yang sedang dipakai deployment.
3. GANTI kelima file di folder tersebut dengan versi baru:
   app.py, requirements.txt, model_bundle_qos_4parameter_CV_TERBAIK.joblib,
   contoh_qos_1.csv, contoh_qos_2.csv.
   Pastikan nama file persis sama dan tidak tersimpan dalam subfolder tambahan.
4. Commit changes.
5. Di Dashboard Streamlit Cloud, pastikan main file path:
   LiveStreamQoS_Cloud/app.py; Python 3.11.
6. Reboot app lalu buka https://livestreamqos.streamlit.app.

Tiga halaman: Home, Prediksi QoS, About.
Pada halaman Prediksi QoS, pilih data contoh lalu klik Mulai Pengujian.
Hasil NORMAL/GANGGUAN merupakan inferensi model XGBoost, bukan Wi-Fi pengunjung.

PENTING: Jika masih muncul layar putih dengan spinner dan Cloud Logs kosong,
masalahnya BELUM TENTU ada pada app.py. Ada laporan gangguan pemuatan JavaScript
pada Streamlit Community Cloud pada November 2026. Periksa F12 -> Network/Console.
Versi Streamlit di sini dipin ke 1.44.1 untuk eksperimen kompatibilitas,
tetapi perubahan versi tidak menjamin memperbaiki gangguan server.
