LIVESTREAMQOS - APLIKASI BARU KHUSUS MODEL TERBAIK DARI CROSS-VALIDATION
======================================================================

Ini aplikasi TERPISAH. app.py lama Anda tidak diubah.

LANGKAH WINDOWS (CMD):
1. Ekstrak ZIP ini ke sebuah FOLDER BARU.
2. Buka CMD di dalam folder baru tersebut.
3. Install paket:
      python -m pip install -r requirements.txt
4. Jalankan:
      python -m streamlit run app.py
5. Di website, pilih adaptor Wi-Fi yang dipakai laptop, lalu klik "Mulai Monitoring".
6. Tunggu 12 sampel QoS valid, kurang lebih 60 detik jika semua ping berhasil.

Aplikasi akan memilih model terbaik dari file joblib SECARA OTOMATIS.
Pada bundle hasil 4-fold Cross-Validation lokal saat ini: XGBoost.
Jangan mengganti file joblib dengan model lama.

KOLOM YANG DIUKUR:
Latency, Jitter, Packet Loss, Throughput UPLOAD (Mbps).
Fitur model: 6 statistik x 4 parameter = 24 fitur.
Sampling: sekali per 5 detik; riwayat 12 sampel; horizon prediksi 60 detik.

Hasil otomatis tersimpan sebagai CSV dalam folder riwayat_model_terbaik.
CSV pengukuran menyertakan data tidak valid dengan statusnya.
CSV prediksi hanya menyimpan prediksi ketika 12 sampel valid telah tersedia.

BATASAN ILMIAH:
- Label pelatihan adalah indikasi kondisi QoS; bukan bukti gangguan streaming aktual.
- Paket tidak memodifikasi hasil pengujian atau threshold.
- XGBoost dipilih berdasarkan skor validasi lintas fold. Pada holdout, model lain
  dapat memiliki metrik lebih tinggi; hal ini dibahas pada halaman evaluasi.
- Sampel gagal/putus ping tidak dikarang atau diisi angka nol.
- Jika rentang 12 sampel valid >75 detik, prediksi diberi peringatan karena
  tidak lagi setara dengan riwayat 60 detik yang utuh.

Model menggunakan scikit-learn 1.8.0 dan xgboost 3.1.3.
Untuk menggunakan bundle hasil training ulang Colab, sesuaikan versi paket
menurut metadata model sebelum memuatnya.
