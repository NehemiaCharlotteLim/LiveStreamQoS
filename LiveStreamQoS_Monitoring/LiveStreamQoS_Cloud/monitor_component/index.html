MENUNGGU DATA
Memerlukan 12 pengukuran valid. Model memprediksi QoS 60 detik ke depan.
Metode: Pengukuran menggunakan HTTP browser, termasuk unduh HTTP untuk throughput. Model XGBoost menghasilkan label dari 24 fitur turunan (12 pengukuran), tanpa aturan ambang manual pada aplikasi. Makna label: Normal QoS indikatif / Penurunan QoS indikatif untuk sekitar 60 detik berikutnya, bukan bukti gangguan tayangan. Label data latih adalah proxy QoS empiris; perbedaan data HTTP dengan data latih perlu divalidasi.
